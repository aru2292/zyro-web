Questions

  

    
Do I need to pay to use ZYRO?
No. Core security, music, moderation and voice rooms are free. Premium adds the second antinuke layer and extra tools.

    
Does ZYRO read my messages?
Only to run commands and the features you turn on. Message content is not used for AI training. See the privacy policy.

    
What do I need for the antinuke to work?
Put ZYRO's role at the very top of the role list, then run &antinuke enable. Run &zyrocheck to verify.

    
How do I get Premium?
Join the support server and ask. Premium is granted by the team and activated per server with &premium activate.
